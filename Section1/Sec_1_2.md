# جلسه اول 

##  بخش دوم:  انواع اشیا در R؛ بردارها و لیست‌ها 🧬

در تحلیل داده‌های پژوهشی، تقریباً هیچ‌گاه با یک مقدار منفرد سروکار نداریم. داده‌های واقعی معمولاً شامل مجموعه‌ای از مقادیر هستند؛ برای مثال وزن چندین ماهی، طول چندین میگو، غلظت اکسیژن محلول در چند ایستگاه، یا نتایج چند تیمار آزمایشی. در زبان R، پایه‌ای‌ترین ساختار برای نگهداری مجموعه‌ای از مقادیر هم‌نوع، **بردار** است.

---

## مفهوم شیء در R 🧪

در R تقریباً هر چیزی که می‌سازید یک **شیء** است. متغیر عددی، متن، بردار، لیست، جدول داده، مدل آماری و حتی خروجی یک آزمون آماری، همگی شیء محسوب می‌شوند.

برای مثال:

```r
final_weight <- 18.6
species <- "Litopenaeus vannamei"
survived <- TRUE
```

در اینجا سه شیء ساخته شده است:

- یک شیء عددی برای وزن نهایی
- یک شیء متنی برای نام گونه
- یک شیء منطقی برای وضعیت بقا

با اجرای کد زیر می‌توان اشیای موجود در محیط کاری را مشاهده کرد:

```r
ls()
```

برای حذف یک شیء از محیط کاری:

```r
rm(final_weight)
```

در پژوهش‌های واقعی، مدیریت اشیا اهمیت زیادی دارد؛ زیرا ممکن است در طول یک تحلیل، چندین نسخه از داده‌ها، خروجی‌ها و مدل‌ها در محیط R ساخته شوند.

---

## بردار چیست؟ 📌

بردار ساده‌ترین و مهم‌ترین ساختار داده در R است. یک بردار مجموعه‌ای از مقادیر هم‌نوع است؛ یعنی همه عناصر آن باید از یک نوع داده باشند.

نمونه‌هایی از بردار در پژوهش‌های شیلاتی:

- وزن ۱۰ عدد ماهی
- طول کل چند نمونه ماهی
- شوری آب در چند ایستگاه
- دمای آب در روزهای مختلف
- نام چند گونه آبزی
- وضعیت زنده‌مانی چند نمونه

برای مثال، وزن پنج میگو در پایان دوره پرورش را می‌توان به‌صورت یک بردار عددی ذخیره کرد:

```r
shrimp_weight <- c(15.2, 16.8, 14.9, 17.1, 16.3)
shrimp_weight
```

خروجی:

```r
[1] 15.2 16.8 14.9 17.1 16.3
```

تابع `()c` برای ترکیب چند مقدار و ساخت یک بردار استفاده می‌شود. نام این تابع از واژه combine گرفته شده است.

---

## نکته مهم درباره هم‌نوع بودن عناصر بردار ⚠️

در R همه عناصر یک بردار باید از یک نوع باشند. اگر در یک بردار، مقدار عددی و متنی را با هم ترکیب کنید، R معمولاً همه را به متن تبدیل می‌کند.

```r
mixed_vector <- c(12.5, "Control", 15.8)
mixed_vector
class(mixed_vector)
```

خروجی:

```r
[1] "12.5"    "Control" "15.8"   
[1] "character"
```

این رفتار در تحلیل داده‌ها می‌تواند باعث خطای جدی شود؛ زیرا مقادیر عددی ممکن است ناخواسته به متن تبدیل شوند. برای داده‌های پژوهشی، بهتر است هر ستون یا هر بردار فقط یک نوع داده داشته باشد.

## ساخت بردار با تابع `()scan`

تابع `()scan` برای ورود سریع داده‌ها به R استفاده می‌شود. این تابع به‌ویژه زمانی مفید است که پژوهشگر بخواهد چند مقدار عددی را سریع از صفحه‌کلید یا از یک فایل ساده وارد کند.

### ورود داده از صفحه‌کلید

```r
weights <- scan()
```

پس از اجرای دستور، R منتظر ورود داده می‌ماند. می‌توان مقادیر را وارد کرد و در پایان با یک خط خالی ورود داده را متوقف نمود.

نمونه داده قابل ورود:

```r
12.4 13.1 14.8 15.0 13.9
```

پس از پایان ورود داده:

```r
weights
```

---

### ورود داده متنی با `()scan`

برای داده متنی باید نوع داده مشخص شود.

```r
sites <- scan(what = character())
```

نمونه داده قابل ورود:

```r
Station_A Station_B Station_C
```

---

### خواندن داده از فایل متنی

اگر فایل متنی ساده‌ای شامل وزن‌ها وجود داشته باشد، می‌توان آن را با `()scan` خواند.

```r
weights <- scan("weights.txt")
weights
```

اگر داده‌ها متنی باشند:

```r
species <- scan("species.txt", what = character())
species
```

تابع `()scan` برای داده‌های ساده مناسب است. برای داده‌های جدولی کامل، در بخش‌های بعدی از توابع تخصصی‌تر ورود داده استفاده خواهد شد.

## اسلایس کردن با شرط

یکی از قابلیت‌های مهم R، انتخاب عناصر بردار بر اساس شرط است.

```r
shrimp_weight <- c(15.2, 16.8, 14.9, 17.1, 16.3)

shrimp_weight > 16
```

خروجی:

```r
[1] FALSE  TRUE FALSE  TRUE  TRUE
```

این خروجی یک بردار منطقی است. حال می‌توان از همین بردار منطقی برای انتخاب مقادیر استفاده کرد.

```r
shrimp_weight[shrimp_weight > 16]
```

خروجی:

```r
[1] 16.8 17.1 16.3
```

این روش در تحلیل داده‌های پژوهشی بسیار کاربرد دارد؛ مثلاً انتخاب ماهی‌هایی با وزن بالاتر از حد مشخص، انتخاب ایستگاه‌هایی با اکسیژن پایین، یا انتخاب نمونه‌هایی با طول بیشتر از مقدار آستانه.

---

## مثال‌های شرطی در داده‌های شیلاتی

### انتخاب دماهای بالاتر از حد مطلوب

```r
temperature <- c(27.5, 28.1, 31.2, 29.4, 32.0, 26.8)

high_temperature <- temperature[temperature > 30]
high_temperature
```

---

### انتخاب شوری‌های کمتر از مقدار بحرانی

```r
salinity <- c(12, 18, 25, 30, 8, 15)

low_salinity <- salinity[salinity < 10]
low_salinity
```

---

### انتخاب وزن‌های در محدوده مطلوب

```r
fish_weight <- c(85, 92, 110, 76, 98, 120)

selected_weight <- fish_weight[fish_weight >= 90 & fish_weight <= 110]

```

## کار با مقادیر گمشده در بردارها ⚠️

در داده‌های پژوهشی، وجود مقدار گمشده رایج است. ممکن است وزن یک نمونه ثبت نشده باشد، سنسور دما در یک روز خطا داده باشد، یا داده اکسیژن محلول برای یک ایستگاه موجود نباشد.

در R مقدار گمشده با `NA` نمایش داده می‌شود.

```r
shrimp_weight <- c(15.2, 16.8, NA, 17.1, 16.3)
shrimp_weight
```

اگر روی برداری که دارای `NA` است میانگین بگیریم:

```r
mean(shrimp_weight)
```

خروجی:

```r
[1] NA
```

برای حذف مقادیر گمشده از محاسبه:

```r
mean(shrimp_weight, na.rm = TRUE)
```

تابع‌های زیر نیز آرگومان `na.rm` را می‌پذیرند:

```r
sum(shrimp_weight, na.rm = TRUE)
min(shrimp_weight, na.rm = TRUE)
max(shrimp_weight, na.rm = TRUE)
sd(shrimp_weight, na.rm = TRUE)
```

برای بررسی وجود مقدار گمشده:

```r
is.na(shrimp_weight)
```

برای انتخاب مقادیر غیرگمشده:

```r
shrimp_weight[!is.na(shrimp_weight)]
```

## محاسبات برداری در R 🧮

یکی از ویژگی‌های قدرتمند R، انجام محاسبات مستقیم روی بردارهاست. اگر یک عمل ریاضی را روی بردار انجام دهید، R آن را روی تمام عناصر بردار اعمال می‌کند.

```r
initial_weight <- c(2.1, 2.3, 2.0, 2.4, 2.2)
final_weight <- c(15.2, 16.8, 14.9, 17.1, 16.3)

weight_gain <- final_weight - initial_weight
weight_gain
```

خروجی:

```r
[1] 13.1 14.5 12.9 14.7 14.1
```

محاسبه نرخ رشد ویژه برای چند تکرار:

```r
days <- 60

sgr <- (log(final_weight) - log(initial_weight)) / days * 100
sgr
```

فرمول نرخ رشد ویژه:

$$
SGR(\%) = \frac{\ln(W_f) - \ln(W_i)}{t} \times 100
$$

محاسبه درصد افزایش وزن:

```r
weight_gain_percent <- (final_weight - initial_weight) / initial_weight * 100
weight_gain_percent
```

فرمول درصد افزایش وزن:

$$
WG(\%) = \frac{W_f - W_i}{W_i} \times 100
$$

## مقایسه برداری و تولید خروجی منطقی

در R می‌توان بردارها را با مقدار آستانه یا با بردار دیگر مقایسه کرد.

```r
dissolved_oxygen <- c(5.8, 4.9, 6.2, 5.1, 3.8)

oxygen_ok <- dissolved_oxygen >= 5
oxygen_ok
```

خروجی:


## لیست چیست؟ 🧩

لیست در R ساختاری انعطاف‌پذیرتر از بردار است. برخلاف بردار که همه عناصر آن باید هم‌نوع باشند، یک لیست می‌تواند اشیای مختلف با انواع متفاوت را در کنار هم نگهداری کند.

برای مثال، در یک مطالعه رشد میگو ممکن است بخواهیم اطلاعات زیر را در یک شیء واحد ذخیره کنیم:

## مثال واقعی پایان بخش: سازمان‌دهی داده‌های اولیه یک آزمایش رشد میگو 🦐📌

در یک آزمایش رشد، پژوهشگری اثر مکمل پروبیوتیک را بر رشد میگوی وانامی بررسی کرده است. داده‌های اولیه و نهایی پنج تکرار آزمایشی به‌صورت زیر ثبت شده‌اند:

| تکرار | وزن اولیه | وزن نهایی | تعداد اولیه | تعداد نهایی |
|---|---:|---:|---:|---:|
| ۱ | 2.1 | 15.2 | 100 | 94 |
| ۲ | 2.3 | 16.8 | 100 | 96 |
| ۳ | 2.0 | 14.9 | 100 | 91 |
| ۴ | 2.4 | 17.1 | 100 | 95 |
| ۵ | 2.2 | 16.3 | 100 | 94 |

هدف، ذخیره داده‌ها در بردارها، محاسبه شاخص‌های اولیه رشد و بقا، سازمان‌دهی اطلاعات در یک لیست و ذخیره خلاصه نتایج در فایل متنی است.

```r
species <- "Litopenaeus vannamei"
treatment <- "Probiotic"
days <- 60

replicate_id <- 1:5
initial_weight <- c(2.1, 2.3, 2.0, 2.4, 2.2)
final_weight <- c(15.2, 16.8, 14.9, 17.1, 16.3)
initial_number <- c(100, 100, 100, 100, 100)
final_number <- c(94, 96, 91, 95, 94)

weight_gain <- final_weight - initial_weight
sgr <- (log(final_weight) - log(initial_weight)) / days * 100
survival_rate <- final_number / initial_number * 100

mean_initial_weight <- mean(initial_weight)
mean_final_weight <- mean(final_weight)
mean_weight_gain <- mean(weight_gain)
mean_sgr <- mean(sgr)
mean_survival_rate <- mean(survival_rate)

shrimp_trial <- list(
  species = species,
  treatment = treatment,
  days = days,
  replicate_id = replicate_id,
  initial_weight = initial_weight,
  final_weight = final_weight,
  initial_number = initial_number,
  final_number = final_number,
  weight_gain = weight_gain,
  sgr = sgr,
  survival_rate = survival_rate
)

str(shrimp_trial)

cat("Species:", shrimp_trial$species, "\n",
    "Treatment:", shrimp_trial$treatment, "\n",
    "Culture days:", shrimp_trial$days, "\n",
    "Mean initial weight:", mean_initial_weight, "g\n",
    "Mean final weight:", mean_final_weight, "g\n",
    "Mean weight gain:", mean_weight_gain, "g\n",
    "Mean SGR:", mean_sgr, "% per day\n",
    "Mean survival rate:", mean_survival_rate, "%\n",
    file = "shrimp_trial_summary.txt")
```

در این مثال، داده‌های خام در قالب بردارها ذخیره شده‌اند، محاسبات اصلی به‌صورت برداری انجام شده است، سپس کل اطلاعات آزمایش در یک لیست منظم قرار گرفته و خلاصه نتایج در یک فایل متنی ذخیره شده است. این الگو، پایه ورود به ساختارهای جدولی و تحلیل‌های آماری در بخش‌های بعدی خواهد بود.

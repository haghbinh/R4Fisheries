# جلسه اول
##  بخش سوم: انواع اشیا در R؛ داده‌های چارچوب‌دار  📊
---

در پژوهش‌های واقعی، داده‌ها معمولاً به‌صورت یک مقدار منفرد یا یک بردار ساده ذخیره نمی‌شوند، بلکه در قالب یک جدول ثبت می‌شوند. برای مثال، در یک مطالعه رشد میگو ممکن است برای هر تکرار آزمایشی ستون‌هایی مانند شناسه استخر، تیمار، وزن اولیه، وزن نهایی، تعداد اولیه، تعداد نهایی، شوری، دما و اکسیژن محلول ثبت شود. در R، یکی از ساختارهای اصلی برای نگهداری این نوع داده‌های جدولی، `data.frame` است.

## داده‌های چارچوب‌دار چیست؟ 🧪

داده‌های چارچوب‌دار یا `data.frame` ساختاری جدولی در R هستند که در آن:

- هر **سطر** معمولاً یک مشاهده، نمونه، تکرار یا واحد آزمایشی است.
- هر **ستون** یک متغیر پژوهشی است.
- ستون‌ها می‌توانند نوع‌های متفاوتی داشته باشند؛ برای مثال یک ستون عددی، ستون دیگر متنی و ستون دیگر طبقه‌ای باشد.

در علوم شیلات، آبزیان و میگو، مثال‌های رایج از داده‌های جدولی عبارت‌اند از:

- داده‌های رشد چند تکرار آزمایشی
- داده‌های کیفیت آب در ایستگاه‌های مختلف
- داده‌های زیست‌سنجی طول و وزن ماهیان
- داده‌های بقا در تیمارهای مختلف
- داده‌های ترکیب لاشه یا ترکیب شیمیایی خوراک
- داده‌های تراکم پلانکتون یا فراوانی گونه‌ها

---

## چرا `data.frame` مهم است؟ 🔬

بیشتر تحلیل‌های آماری، ترسیم نمودارها و مدل‌سازی‌ها در R بر پایه داده‌های جدولی انجام می‌شوند. اگر داده‌های پژوهشی شما در قالب `data.frame` منظم باشند، در مراحل بعدی می‌توانید:

- تحلیل توصیفی انجام دهید
- داده‌ها را فیلتر یا مرتب کنید
- آزمون‌های آماری اجرا کنید
- نمودارهای علمی ترسیم کنید
- مدل‌های آماری بسازید
- خروجی‌ها را برای مقاله یا گزارش آماده کنید

بنابراین `data.frame` یکی از بنیادی‌ترین اشیای R برای تحلیل داده‌های پژوهشی است.

---

## ساخت `data.frame` با داده‌های ساده

برای ساخت یک `data.frame` از تابع `data.frame()` استفاده می‌شود.

مثال زیر داده‌های ساده یک آزمایش رشد میگو را نشان می‌دهد:

```r
shrimp_data <- data.frame(
  pond_id = c("P1", "P2", "P3", "P4"),
  treatment = c("Control", "Probiotic", "Control", "Probiotic"),
  initial_weight = c(2.1, 2.3, 2.0, 2.2),
  final_weight = c(15.2, 16.8, 14.9, 16.1),
  survival_rate = c(94, 96, 91, 95)
)

shrimp_data
```

خروجی به‌شکل یک جدول خواهد بود:

```r
  pond_id  treatment initial_weight final_weight survival_rate
1      P1    Control            2.1         15.2            94
2      P2 Probiotic            2.3         16.8            96
3      P3    Control            2.0         14.9            91
4      P4 Probiotic            2.2         16.1            95
```

در این جدول:

- هر سطر یک واحد مشاهده است.
- هر ستون یک متغیر پژوهشی است.

---

## ویژگی‌های اصلی `data.frame`

یک `data.frame` چند ویژگی مهم دارد که پژوهشگر باید آن‌ها را به‌خوبی بشناسد.

### هر ستون یک متغیر است

برای مثال در داده زیر:

- `pond_id` شناسه استخر
- `treatment` نوع تیمار
- `initial_weight` وزن اولیه
- `final_weight` وزن نهایی
- `survival_rate` درصد بقا

---

### هر سطر یک مشاهده است

در مثال بالا، هر سطر می‌تواند یک استخر، یک تکرار یا یک واحد آزمایشی باشد.

---

### ستون‌ها می‌توانند نوع متفاوت داشته باشند

برای مثال:

- `pond_id` متنی است
- `treatment` متنی یا طبقه‌ای است
- `initial_weight` عددی است
- `final_weight` عددی است
- `survival_rate` عددی است

این یکی از تفاوت‌های مهم `data.frame` با بردار است. در بردار همه عناصر باید هم‌نوع باشند، اما در `data.frame` هر ستون می‌تواند نوع خاص خود را داشته باشد.

---

### طول همه ستون‌ها باید برابر باشد

در هنگام ساخت `data.frame`، تعداد عناصر همه ستون‌ها باید یکسان باشد. اگر یک ستون ۴ مقدار داشته باشد و ستون دیگر ۵ مقدار، R خطا می‌دهد.

نمونه نادرست:

```r
data.frame(
  pond_id = c("P1", "P2", "P3"),
  final_weight = c(15.2, 16.8)
)
```

## ورود داده‌ها با `()read.table` 📥

در پروژه‌های واقعی معمولاً داده‌ها از قبل در فایل ذخیره شده‌اند و پژوهشگر آن‌ها را از فایل وارد R می‌کند. یکی از توابع پایه برای خواندن داده‌های متنی جدولی، `read.table()` است.

این تابع برای فایل‌هایی مناسب است که به‌صورت متنی ذخیره شده‌اند؛ مانند:

- فایل‌های متنی ساده
- فایل‌های tab-delimited
- فایل‌های space-delimited
- فایل‌های متنی قابل صدور از Excel یا نرم‌افزارهای دیگر

---

## ساختار کلی `()read.table`

ساختار پایه به‌شکل زیر است:

```r
data_name <- read.table("file_name.txt", header = TRUE)
```

در اینجا:

- `"file_name.txt"` نام فایل ورودی است
- `header = TRUE` یعنی سطر اول فایل شامل نام ستون‌هاست

---

## مثال ساده از `()read.table`

فرض کنید فایل متنی زیر وجود دارد:

```text
pond_id treatment initial_weight final_weight
P1 Control 2.1 15.2
P2 Probiotic 2.3 16.8
P3 Control 2.0 14.9
P4 Probiotic 2.2 16.1
```

برای خواندن این فایل:

```r
shrimp_data <- read.table("shrimp_data.txt", header = TRUE)

shrimp_data
```

---

## استفاده از جداکننده‌ها در `()read.table`

گاهی داده‌ها با فاصله، گاهی با tab و گاهی با جداکننده دیگر ذخیره می‌شوند. در چنین حالتی باید جداکننده مناسب مشخص شود.

### فایل tab-delimited

```r
shrimp_data <- read.table("shrimp_data.txt", header = TRUE, sep = "\t")
```

### فایل با جداکننده کاما

اگرچه برای فایل CSV معمولاً از `()read.csv` استفاده می‌شود، ولی می‌توان با `()read.table` نیز آن را خواند:

```r
shrimp_data <- read.table("shrimp_data.csv", header = TRUE, sep = ",")
```

### فایل با جداکننده نقطه ویرگول

```r
shrimp_data <- read.table("shrimp_data.txt", header = TRUE, sep = ";")
```

---

## نکات مهم در استفاده از `()read.table` ⚠️

### وجود نام ستون‌ها

اگر سطر اول فایل نام ستون‌ها باشد، باید `header = TRUE` تنظیم شود.

اگر فایل نام ستون نداشته باشد:

```r
shrimp_data <- read.table("shrimp_data.txt", header = FALSE)
```

در این حالت R خودش نام‌هایی مانند `V1`, `V2`, `V3` تولید می‌کند.

---

### توجه به جداکننده

بسیاری از خطاهای ورود داده به‌دلیل تعیین نکردن جداکننده درست رخ می‌دهد. اگر بعد از ورود داده ببینید همه اطلاعات در یک ستون قرار گرفته‌اند، معمولاً مشکل از `sep` است.

---

### توجه به مسیر فایل

اگر فایل در مسیر کاری جاری نباشد، باید مسیر دقیق فایل مشخص شود.

shrimp_data <- read.table("C:/Users/Haghbin/Desktop/R/shrimp_data.txt", header = TRUE)

در R بهتر است از `/` در مسیر فایل استفاده شود.

## ذخیره داده‌ها با `()write.table` 💾

پس از ساخت، اصلاح یا آماده‌سازی داده‌ها، ممکن است لازم باشد آن‌ها را در فایل ذخیره کنید. تابع پایه برای این کار `()write.table` است.

---

## ساختار کلی `()write.table`

```r
write.table(data_name, file = "output.txt")
```

---

## مثال ساده از ذخیره داده

```r
write.table(pond_data, file = "pond_data_output.txt")
```

پس از اجرای این دستور، فایل متنی شامل جدول داده ساخته می‌شود.

---

## ذخیره با نام ستون‌ها و بدون شماره سطر

در بسیاری از موارد بهتر است شماره سطرها ذخیره نشوند.

```r
write.table(pond_data,
            file = "pond_data_output.txt",
            row.names = FALSE)
```

---

## ذخیره با جداکننده tab

```r
write.table(pond_data,
            file = "pond_data_output.txt",
            sep = "\t",
            row.names = FALSE)
```

---

## ذخیره با جداکننده کاما

```r
write.table(pond_data,
            file = "pond_data_output.csv",
            sep = ",",
            row.names = FALSE)
```

---

## نکات مهم در `()write.table` ⚠️

### حذف شماره سطرها

در بیشتر فایل‌های خروجی پژوهشی بهتر است `row.names = FALSE` استفاده شود؛ زیرا شماره سطرها معمولاً بخشی از داده اصلی نیستند.

---

### تعیین جداکننده مناسب

اگر فایل برای استفاده در Excel یا نرم‌افزار دیگر ذخیره می‌شود، باید جداکننده مناسب انتخاب شود.

- برای فایل متنی tab-delimited از `"sep = "\t`
- برای فایل CSV از `"," = sep `

---

### ذخیره نسخه پاک‌سازی‌شده داده

در کار پژوهشی بهتر است پس از هر مرحله مهم، نسخه‌ای از داده ذخیره شود. برای مثال:

```text
raw_data.txt
clean_data.txt
analysis_data.txt
```

این کار بازتولیدپذیری تحلیل را تقویت می‌کند.

---

## مثال کوچک از ورود و ذخیره داده

فرض کنید داده اولیه‌ای را از فایل وارد کرده‌اید و فقط می‌خواهید نام ستون‌ها را استاندارد کنید و فایل را دوباره ذخیره نمایید.

```r
trial_data <- read.table("trial_data.txt", header = TRUE, sep = "\t")

names(trial_data) <- c("pond_id", "treatment", "initial_weight", "final_weight")

write.table(trial_data,
            file = "trial_data_clean.txt",
            sep = "\t",
            row.names = FALSE)
```

در این بخش عمداً از ورود به جزئیات پردازش بیشتر داده‌ها خودداری می‌شود، زیرا تحلیل توصیفی و کار عملی بیشتر با `data.frame` در جلسه بعد بررسی خواهد شد.

str(fish_data)

گاهی برخی متغیرهای طبقه‌ای به‌صورت برچسب‌دار وارد می‌شوند و در مراحل بعد لازم است برای تحلیل مناسب آماده‌سازی شوند. جزئیات این کار را در مراحل بعدی تحلیل داده بررسی خواهیم کرد.

---

## نکات مهم برای آماده‌سازی فایل قبل از ورود به R 🧭

پیش از ورود داده به R، بهتر است چند اصل رعایت شود:

- هر سطر فقط یک مشاهده باشد.
- هر ستون فقط یک متغیر باشد.
- نام ستون‌ها کوتاه، واضح و بدون فاصله باشد.
- از وارد کردن واحد اندازه‌گیری در داخل سلول‌ها خودداری شود.
- داده عددی فقط به‌صورت عدد ذخیره شود.
- از سلول‌های خالی غیرمنطقی، سطرهای توضیحی و عنوان‌های چندسطری پرهیز شود.
- کدگذاری تیمارها و گروه‌ها از ابتدا منظم باشد.
- فایل خام همیشه بدون تغییر نگهداری شود.

برای مثال، این شکل مناسب نیست:

```text
Weight = 15.2 g
```

و این شکل مناسب است:

```text
15.2
```

واحد اندازه‌گیری باید در نام متغیر، مستندات یا فایل توضیحی ثبت شود، نه در داخل مقدار داده.

## تفاوت فایل خام و فایل تحلیلی

در پروژه‌های پژوهشی بهتر است حداقل دو نسخه از داده‌ها وجود داشته باشد:

- فایل خام: همان داده اولیه ثبت‌شده
- فایل تحلیلی: نسخه‌ای که برای تحلیل در R آماده شده است

نمونه نام‌گذاری:

```text
shrimp_growth_raw.xlsx
shrimp_growth_analysis.txt
```

این شیوه در مستندسازی پژوهش و پاسخ‌گویی به داوران مقاله بسیار مفید است.

## جدول توابع متداول مربوط به `data.frame`

| تابع | کاربرد | نمونه |
|---|---|---|
| `data.frame()` | ساخت داده جدولی | `data.frame(id = c("P1", "P2"), weight = c(15.2, 16.1))` |
| `class()` | بررسی کلاس شیء | `class(shrimp_data)` |
| `str()` | مشاهده ساختار داده | `str(shrimp_data)` |
| `names()` | مشاهده یا تغییر نام ستون‌ها | `names(shrimp_data)` |
| `read.table()` | خواندن فایل متنی جدولی | `read.table("data.txt", header = TRUE)` |
| `write.table()` | ذخیره داده در فایل متنی | `write.table(shrimp_data, file = "out.txt")` |
| `read_excel()` | خواندن فایل Excel | `read_excel("data.xlsx")` |
| `read_sav()` | خواندن فایل SPSS | `read_sav("data.sav")` |

## مثال: ورود و سازمان‌دهی داده‌های رشد و کیفیت آب 🦐📌

در یک مطالعه پرورش میگوی وانامی، داده‌های اولیه در یک فایل جدولی ثبت شده‌اند. هر سطر مربوط به یک استخر آزمایشی است و ستون‌ها شامل شناسه استخر، نوع تیمار، وزن اولیه، وزن نهایی، دما، شوری و اکسیژن محلول هستند. هدف این مرحله فقط ورود داده، بررسی ساختار و ذخیره نسخه منظم برای تحلیل جلسه بعد است.

```r
pond_data <- data.frame(
  pond_id = c("P1", "P2", "P3", "P4", "P5", "P6"),
  treatment = c("Control", "Control", "Probiotic", "Probiotic", "Synbiotic", "Synbiotic"),
  initial_weight = c(2.0, 2.1, 2.2, 2.3, 2.1, 2.2),
  final_weight = c(14.8, 15.1, 16.4, 16.9, 17.2, 17.0),
  temperature = c(28.4, 28.7, 29.1, 28.9, 29.0, 28.8),
  salinity = c(18, 19, 20, 20, 21, 21),
  dissolved_oxygen = c(5.6, 5.4, 5.9, 5.7, 6.0, 5.8)
)

write.table(pond_data,
            file = "pond_data_session1.txt",
            sep = "\t",
            row.names = FALSE)
            
```
